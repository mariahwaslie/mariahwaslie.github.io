About

The short version.

I gravitate toward the hard part of machine learning — messy data, real modeling depth, and the question of whether a model actually works once it leaves the notebook. I care equally about the backend systems that serve predictions and the data pipelines that feed them.

During my internship at Royal Credit Union, I built ML models across three workstreams — organizational churn prediction, credit card adoption, and product recommendation — evaluating 10+ model architectures and deploying 3 to production via OracleDB, serving 500K+ members. I worked in both Python and R, with Oracle SQL for feature engineering.

Since then I've built a deployed RAG application, a calibrated loan-default prediction system on 1M+ real records, and I'm currently architecting a FHIR-compliant clinical risk platform in Java and Python.
